# Guías para Expo y React Native

Al trabajar en aplicaciones móviles asociadas a este proyecto usando Expo:
- Prioriza el uso de componentes funcionales y Hooks de **React Native**.
- Utiliza las APIs y bibliotecas recomendadas por el **Expo SDK**.
- Mantén una separación clara entre lógica de negocio y presentación.
- Usa **Expo Router** o React Navigation según la configuración para el enrutamiento.
- Asegúrate de considerar el diseño responsivo y el comportamiento multiplataforma (iOS / Android).
